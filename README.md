# Nib

A tiny alternative to Nano

> [!IMPORTANT]
> Install Python 3.8 or newer before running the command for your platform.

### macOS / Linux

```sh
curl -fsSL https://github.com/Ka1bOne/nib/releases/latest/download/install.py | python3 -
```

### Windows PowerShell

```powershell
(Invoke-RestMethod 'https://github.com/Ka1bOne/nib/releases/latest/download/install.py') | py -3 -
```

> [!TIP]
> Open a new terminal and type `nib` for the home menu, or `nib test.py` to edit a file.
